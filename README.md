# Завдання 1 — АЦП → STM32 → ЦАП на 5 МSPS

Зчитування зовнішнього 8-бітного АЦП з паралельною шиною, обробка вибірок і вивід
результату на 8-бітний ЦАП з паралельною шиною. Уся передача даних — на DMA і
таймерах, ядро виконує лише розрахунок.

Розробка — [hopeok.com.ua](https://hopeok.com.ua/)

## Умова і як вона реалізована

| З умови | Реалізація |
|---|---|
| АЦП, 8-бітна паралельна шина | читання порту GPIOC цілим байтом через DMA |
| 1024 зразки по три семпли | 3072 вибірки на вході, 1024 значення на виході |
| швидкість 5 МSPS | TIM2, період 34 такти при 170 МГц = рівно 5,000 МГц |
| `P1[i] = S1[i] + S3[i] − 2·S2[i]` | обробка трійками, крок 3, вікна не перекриваються |
| ЦАП, 8-бітна паралельна шина | запис у порт GPIOB через DMA від TIM3 |
| DMA і таймери | два канали DMA, ядро не бере участі в передачі |

## Підключення

| Сигнал | Вивід | Призначення |
|---|---|---|
| Дані АЦП | `PC0…PC7` | вхідна шина, читається цілим байтом |
| CLK АЦП | `PA0` | TIM2 CH1, меандр 5 МГц |
| Дані ЦАП | `PB0…PB7` | вихідна шина |
| Строб ЦАП | `PA6` | TIM3 CH1, фіксація даних у засувці |
| Індикація | `PA5` | світлодіод плати |

Конкретні мікросхеми АЦП і ЦАП умовою не задані. Схема розрахована на будь-яку
пару з паралельним інтерфейсом і зовнішнім тактуванням — наприклад AD9280 на
вході та AD9708 або R-2R-збірка з засувкою на виході.

## Часова база

Усе рахується від 170 МГц, один такт таймера — 5,882 нс.

| | Період | Частота |
|---|---|---|
| TIM2 — вхід | 34 такти = 200 нс | 5,000 МГц |
| TIM3 — вихід | 102 такти = 600 нс | 1,667 МГц |

Співвідношення рівно 3:1 задане апаратно: `102 = 3 × 34`. На кожні три вхідні
вибірки припадає один вихідний відлік, і цей зсув не може розсинхронізуватися.

Момент читання шини зміщений відносно фронту CLK на 70,6 нс, ще 20…45 нс займає
арбітраж DMA — реальне зчитування припадає на середину вікна, де дані АЦП уже
дійсні й ще не змінилися. Строб ЦАП зміщений на 300 нс після оновлення даних.

Детальні розрахунки — у `docs/технічні-нотатки.md`.

## Збірка

Проєкт відкривається в STM32CubeIDE. Для збірки без середовища розробки:

```
cd firmware
make
```

Шлях до компілятора задається змінною `GCC_PATH` у верхній частині `Makefile`.
Прошивка — `flash.bat` або `make flash`.

## Перевірка на платі

| Показник | Результат |
|---|---|
| Частота дискретизації | **4,99976 МSPS** при розрахункових 5,000 |
| Пропущені кадри | **0** за 357 секунд безперервної роботи |
| Помилки DMA | **0** |
| FLASH | 9 024 Б |
| RAM | 6 052 Б |

Стан конвеєра виведений на світлодіод: рівне блимання раз на секунду — норма,
часте — був зрив або помилка DMA. Період відлічується кадрами DMA, а не таймером,
тому світлодіод завмирає саме тоді, коли став конвеєр.
